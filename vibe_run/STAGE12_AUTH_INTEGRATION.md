# ARGOS-VIBE — этап 12: HMAC интеграция (проверенная версия X230)

## Фактически реализовано
- Vibe `message_auth.py` подписывает и проверяет HMAC-SHA256 канонического JSON.
- `daemon.py` при наличии `ARGOS_LINK_SECRET` подписывает конверт результата **до** загрузки на x0.at.
- `x230_link.py` подписывает отдельное ntfy-уведомление с URL, SHA256, `result_msg_id`, `in_reply_to` и `created_utc`. Подпись всего конверта и уведомления проверяется на X230.
- Входящие задания с HMAC проверяются до постановки в SQLite. `ARGOS_LINK_AUTH_REQUIRED=1` запрещает неподписанные задания и исходящие результаты в Vibe.
- Приёмник X230 проверяет подписи, обязательное совпадение `result_msg_id`, известный идентификатор задания, лимиты размеров, точный HTTPS-хост x0.at, срок подписи уведомления (10 минут), а также подавляет дубли.
- По умолчанию до обмена ключом остаётся режим совместимости: незаверенные ответы хранятся как `authenticated=0`. Активировать строгое отклонение можно **только после** подтверждённого обмена подписью обеими сторонами.

## Ключ и доверенная доставка
- В GitHub, x0.at, ntfy и сообщениях чата **нет ключа**. Нужны 32 криптографически случайных байта, представленные 64 hex-символами.
- X230 запрашивает RootGuard на генерацию root-only ключа и передачу процессу через systemd `LoadCredential`. Это хранение в защищённом локальном файле для сохранения после перезапуска, а не публикация ключа.
- Передача в Vibe **не выполнялась**. Не отправляйте ключ в публичный канал; нужен проверенный публичный ключ песочницы Vibe для шифрования передачи или другой уже доверенный защищённый транспорт.
- Один `key_id = sha256(secret_ascii_hex)[:8]` удобен для проверки совпадения, но **не является** доказательством владения ключом; оно появляется только после успешной проверки HMAC.
- HMAC гарантирует аутентичность и целостность в рамках тайного ключа, **не конфиденциальность**: текст результата остаётся публичным на x0.at.

## Активация в песочнице
1. Сохранить текущую SQLite-память, очередь задач, `x230_link_state.json`.
2. Обновить `message_auth.py`, `daemon.py`, `x230_link.py` из ветки `vibe/argos-vibe-stage1-12-review-20261114`, не затронув Qwen/MCP/gateway.
3. Сформировать локальную асимметричную пару ключей для **шифрованной** передачи секрета с X230; передать только публичный ключ и его SHA256, без приватного ключа.
4. Прежде чем передавать HMAC-секрет, удостовериться в подлинности публичного ключа через доверенный канал владельца.
5. После безопасной доставки секрета установить `ARGOS_LINK_SECRET` в защищённое окружение демона Vibe. Выполнить один подписанный тест и сверить его receipt X230. Только затем включить `ARGOS_LINK_AUTH_REQUIRED=1` на обеих сторонах.
