# ARGOS REBOOT — восстановление ARGOS Universal OS

**Публичная страница восстановления:** https://reboot-static-production.up.railway.app

3 августа 2026 года пожар уничтожил локальную вычислительную среду, на которой разрабатывался и запускался ARGOS Universal OS. Исходный код и часть материалов проекта сохранились в GitHub и облачных копиях, поэтому проект можно восстановить — но для нормальной работы снова нужен постоянный вычислительный узел.

## Stage 1 — 200 000 ₽

Цель первого этапа — вернуть **ARGOS Core** в стабильный режим 24/7.

Средства Stage 1 предназначены для:

- сервера/рабочей станции под ARGOS Core с возможностью расширения памяти (ориентир — около 128 ГБ RAM);
- локального хранилища для моделей, памяти проекта, сборок и телеметрии;
- резервного копирования, чтобы повторная потеря одного компьютера больше не уничтожала рабочую среду;
- базовой круглосуточной инфраструктуры для API, P2P-узлов и восстановления сервисов ARGOS.

GPU/FPGA и дальнейшее расширение — это следующие этапы. Сейчас приоритет — вернуть устойчивое ядро и резервирование.
