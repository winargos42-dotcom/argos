# ARGOS — paid engineering pilot / платный инженерный пилот

**Status:** accepting written enquiries for small, fixed-scope paid work. ARGOS is an independent engineering project, not an authorised service centre for any device vendor.

## Service A — Local AI / MCP / API integration

A scoped integration of one approved API, MCP tool, database read endpoint or local Ollama service into a customer's test environment.

**Paid deliverables, as agreed in writing:** source code or adapter, installation notes, reproducible test cases, a short acceptance report and limitations. Initial work is **read-only and sandboxed** unless separately authorised.

**Inputs required:** API documentation or a non-production test endpoint, a written use case, acceptance criteria and authorised test credentials (shared privately through an agreed secure channel, never in GitHub issues).

## Service B — Russian technical documentation and localisation

For one product model and one official software/documentation version: Russian glossary, setup guide, FAQ draft and a terminology/placeholder QA report.

**Inputs required:** vendor-approved documents/resources, the exact model/version, reviewer and use permissions.

**Example of a public, binary-free localisation/QA method:** https://github.com/jackhumbert/fardriver-controllers/pull/2 — an **independent open PR under review**, NOT a merged vendor contribution, certification, licensing agreement or manufacturer endorsement.

## Service C — Compatibility QA (only where hardware is available)

Linux/Android/IoT integration and evidence-based diagnostics with a model-specific, approved test plan. No claims of testing unowned devices.

**Out of scope without separate written authorisation:** controller parameter changes, battery protection or high-energy live tests, firmware flashing/signing, warranty/RMA decisions, repairs and safety-critical operations.

## Commercial terms / порядок работы

1. Customer emails a **specific paid task**, device/model or API, permitted test inputs, target completion date and a proposed budget.
2. We reply with a **fixed written quote and scope of work**, including milestones, acceptance tests, ownership/licence terms, payment method and confidentiality terms.
3. Work starts only after the quote and payment arrangement are agreed. No presumed unpaid proof-of-work or free hardware is required.
4. Written collaboration is preferred. No telephone or video call is required.

**Not a claim:** ARGOS has no manufacturer partnership, accepted customer contract or guaranteed SLA merely because this page exists. Experimental public demos are not production SLAs.
