# Проверяемые результаты команд панели

Runtime раньше считал эмодзи доказательством выполнения и терял явный
`execution_status` обработчика. Патч сохраняет структурированный статус,
оставляет текстовые обещания `unverified` и распознаёт недоступные устройства.

Это патч для runtime, а не замена исторического `src/` в корне репозитория.
`patch-hashes.json` задаёт точные SHA256 файлов до и после изменения.
Проверяйте исходные хеши, сохраняйте резервную копию и применяйте патч только
к совпадающему дереву. Команда проверки: `git apply --check execution-truth.patch`.
Тест запускается с корнем совместимого runtime в `PYTHONPATH`:
`python -m pytest test_execution_truth.py`. Он использует настоящую SQLite-очередь.
