# Рабочие изменения ARGOS — 27.09.2026

Эти пакеты сохраняют проверенные изменения действующего Python-runtime.
Корневой `src/` репозитория исторический: он не является полным снимком
сегодняшнего развёртывания. Перед переносом изменений определите реальный
runtime через текущую карту системы и проверьте хеши исходных файлов.

| Пакет | Изменение |
|---|---|
| [discovery](discovery/README.md) | Проверяемые IP, пути, API и Git-репозитории; актуализация памяти; CLI/API и таймер |
| [execution-truth](execution-truth/README.md) | Статус команды следует результату обработчика; эмодзи не доказывают выполнение |
| [panel-ui](panel-ui/README.md) | Текущая карта правильно подписана; HA-ссылки и запоздалые ответы привязаны к сессии |
| [consumers](consumers/README.md) | Камера и свет используют реестр; узлы используют проверенный IP; навыки получают `core`; отсутствующий SNN не выдаётся за обучение |
| [home-assistant](home-assistant/README.md) | Вкладка «Дом», реальные сущности HA, фильтры и метки времени; корректные единицы и защита от устаревших ответов; отдельная панель HA |
| [ha-node-collector](ha-node-collector/README.md) | Телеметрия Coral через актуальный реестр и подписанный API; сквозная проверка API → MQTT → HA, сохранение диагностики X230 |

Текущая карта доступна через защищённый `/api/discovery`. Ресурсы без свежего
подтверждения не используются. Обновление каждые пять минут заменяет один
служебный факт в новой памяти; восстановленные архивы остаются историческими.
SSH проверяет известный ключ и UUID машины. Синхронизация Git выполняется
отдельно, только для чистой ветки с подходящим upstream и fast-forward.

На действующей системе проверены локальные и удалённые команды-маркеры,
состояния сервисов, аутентификация, отказ при устаревших ресурсах, чтение HA
и памяти, а также интерфейс в Chromium на desktop/mobile. Физические
устройства и внешние сообщения эти проверки не затрагивали.

Секреты, приватные реестры машин, базы памяти и резервные копии исходников
в Git не включены. Инструкции и тесты в каждом пакете описывают необходимые
совместимые компоненты runtime и условия применения патча.
