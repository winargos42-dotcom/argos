## 3. КЛЮЧЕВЫЕ КОМПОНЕНТЫ

### 3.1. Основные агенты

| Компонент | Файл | Описание |
|-----------|------|----------|
| **ArgosAgent** | `src/agent.py` | Основной агент, разбивает план на шаги |
| **SubAgencyManager** | `src/sub_agency.py` | Менеджер 8 специализированных агентов |
| **DAGAgent** | `src/dag_agent.py` | Параллельное выполнение графа задач |
| **AgentGuard** | `src/agent_guard.py` | Безопасность, валидация шагов |
| **ArgosAutoPilot** | `autopilot.py` | 5 фоновых потоков мониторинга |

### 3.2. Суб-агенты (SubAgencyManager)

1. **VisionSubAgent** - компьютерное зрение, обработка изображений
2. **CryptoSubAgent** - криптография, блокчейн, безопасность
3. **NetSubAgent** - сетевые операции, P2P, VPN, WireGuard
4. **FilesSubAgent** - работа с файлами, файловая система
5. **ScheduleSubAgent** - планирование задач, cron, таймеры
6. **ContentSubAgent** - генерация контента, тексты, медиа
7. **SystemSubAgent** - системный мониторинг, диагностика
8. **AISubAgent** - AI модели, инференс, оптимизация

## 7. АВТОПИЛОТ

### 7.1. Логика работы
Когда Ava говорит "продолжай на автопилоте":
1. **Чтение логов** - `run.err`, `live_run.err`, `logs/*.log`
2. **Диагностика** - запуск SubAgencyManager + SystemSubAgent + AISubAgent
3. **Параллельная обработка** - использование DAGAgent для графа задач
4. **Применение исправлений** - напрямую через fs/MCP
5. **Отчёт** - что было → что исправил

### 7.2. Фоновые потоки (5 потоков)
1. **Мониторинг системы** - CPU, память, диски
2. **Проверка сети** - доступность узлов, порты
3. **Обновление зависимостей** - pip, пакеты
4. **Резервное копирование** - критичных данных
5. **Анализ логов** - поиск ошибок, аномалий

## ЗАКЛЮЧЕНИЕ

**ARGOS** - это не просто AI-ассистент, а полноценная автономная экосистема, способная:
- Самостоятельно диагностировать и исправлять проблемы

Система построена на модульной архитектуре с чёткими ролями для каждого компонента, что позволяет легко расширять функциональность и поддерживать высокую надёжность.
