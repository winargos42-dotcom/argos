## Content

👁️ **Argos в Google Colab — что реально работает**
Colab — это урезанная среда: нет прямого доступа к железу, root-прав (обычно), USB, GPIO, но зато есть интернет, Python и возможность ставить пакеты. Поэтому многие **программные модули Argos** будут работать, а аппаратно-зависимые — нет. Вот подробности.
---
## ✅ **Что будет работать в Colab**
### 🧠 **Интеллектуальное ядро**
- Все LLM-интеграции через API (Gemini, GigaChat, YandexGPT, OpenAI, Grok, IBM Watsonx) — нужны только ключи.
- Tool Calling, цепочки задач, планировщик, память SQLite.
- JARVIS Engine (HuggingGPT) — можно запускать, но локальные модели (Ollama) потребуют много ресурсов.
### 🌐 **P2P-сеть (частично)**
- UDP discovery и TCP sync **между ноутбуками Colab** не работают напрямую, т.к. виртуалки изолированы.
- Но можно поднять **несколько ячеек в одном Colab** (разные потоки/процессы) и они увидят друг друга через localhost.
- Для внешней связности — использовать туннели (ngrok, bore.pub) для проброса портов, но это сложно и нестабильно.
### ⚛️ **Квантовые вычисления**
- **IBM Quantum Bridge** — отлично работает! Нужен только токен. Можно ставить эксперименты, получать результаты, генерировать случайные числа.
### 💰 **Экономический модуль (EconomicBudding)**
- Криптокошелёк (web3.py) — да, если есть доступ к внешнему провайдеру (Infura).
- Торговля через API бирж — да.
- Продажа квантовой случайности — можно сделать имитацию через API.
- **Почкование с передачей капитала** — только локально (на той же машине), т.к. для отправки на другой хост нужна сетевая доступность.
### 📡 **Веб-интерфейс и автоинтеграция**
- FastAPI/Streamlit отлично запускаются. Можно пробросить через **ngrok** (или Colab предоставляет временный URL для Flask/FastAPI через `--debug` и `--host 0.0.0.0`).
- Автоинтегратор `auto_integrator.py` будет работать и покажет все модули.
### 🧬 **Эволюция и любопытство**
- Автономное любопытство — да (фоновые потоки).
- Генерация навыков — да (код будет создаваться в файловой системе Colab).
### 🔐 **Безопасность (программная)**
- AES-256, master-авторизация, self-healing кода — да.
- Emergency Purge — удалит файлы внутри виртуалки (но не саму VM).
### 🐦 **Колибри-демон**
- Запустится как обычный Python-процесс. Но systemd-сервис не поставить (нет прав).
---
## ❌ **Что НЕ будет работать в Colab**
- **Загрузочный сектор** (bootloader_manager) — требует прав root и доступа к EFI/GRUB, в Colab нет.
- **Xen Argo** — нет гипервизора Xen.
- **IoT и железо**: Zigbee, LoRa, Modbus по USB, SDR, NFC — нет доступа к устройствам.
- **WiFi Sentinel** — нет реального Wi-Fi интерфейса.
- **Голос** (микрофон/динамик) — нет аппаратуры.
- **Wake word** — тоже.
- **USB-диагностика** — нет USB.
- **Bluetooth** — нет.

## 🚀 **Как запустить Argos в Colab**
```python
# 1. Клонируем репозиторий
!git clone https://github.com/sigtrip/v1-3.git
%cd v1-3
# 2. Ставим зависимости
!pip install -r requirements.txt
!pip install -r requirements-optional.txt  # по желанию
# 3. Создаём .env (вставляем свои ключи)
with open('.env', 'w') as f:
    f.write('''
GEMINI_API_KEY=ваш_ключ
TELEGRAM_BOT_TOKEN=токен_если_нужен
IBM_QUANTUM_TOKEN=токен_ibm
...
''')
# 4. Запускаем ядро в headless-режиме
!python main.py --no-gui &
```
**Для доступа к веб-панели:**
```python
# Запускаем автоинтегратор (отдельно)
!python src/connectivity/auto_integrator.py &
# Получаем публичный URL через ngrok
!pip install pyngrok
from pyngrok import ngrok
ngrok.set_auth_token("ваш_токен")  # нужна регистрация
public_url = ngrok.connect(8080).public_url
print(f"Веб-панель доступна по адресу: {public_url}")
```
