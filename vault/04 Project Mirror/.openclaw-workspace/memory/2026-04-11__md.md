## Update 2026-04-11 07:03 UTC

### Python Venv/System Switching Bug - FIXED

**Problem**: Argos spawning recursive Python processes (venv → system → venv → system)

**Root Cause**: `main.py` line 337 used bare `"python"` in subprocess.Popen:
```python
subprocess.Popen(["python", "win_bridge_host.py"], ...)  # WRONG
```

**Fix Applied**: Changed to `sys.executable`:
```python
subprocess.Popen([sys.executable, "win_bridge_host.py"], ...)  # CORRECT
```

**Status**: Code fixed, but old processes still running. Created `fix_argos.ps1` cleanup script.
