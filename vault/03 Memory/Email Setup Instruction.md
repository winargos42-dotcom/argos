## Безопасная настройка

### Шаг 1: Использовать OAuth2 или App Password
1. Создать отдельный App Password или OAuth2 credential для ARGOS.
2. Не записывать реальный секрет в Git, MemPalace, логи, README или примеры.
3. Хранить секрет только в переменных окружения или secret manager.

### Шаг 2: Обновить runtime secrets
```bash
SMTP_PASSWORD=<secret-from-runtime>
ARGOS_EMAIL_PASSWORD=<secret-from-runtime>
```

### Шаг 3: Перезапустить ARGOS
После изменения runtime secrets перезапустить сервис штатным способом.

## Политика отправки

Email-интеграция не является разрешением на автономную внешнюю рассылку. ARGOS может читать входящие и подготавливать черновики, но не должен самостоятельно отправлять письма в support/press/company каналы. Перед фактической отправкой требуется явное подтверждение владельца. Если адресат попросил прекратить прямые обращения, этот канал блокируется до явного нового разрешения адресата.
