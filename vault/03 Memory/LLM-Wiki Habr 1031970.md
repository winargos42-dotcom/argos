## Что такое LLM-Wiki

LLM-Wiki — это подход к созданию "второго мозга", где рутинную работу по поддержке базы знаний выполняет LLM-агент.

### Три слоя системы (Karpathy)

1. **Raw sources** — неизменяемые исходники (статьи, PDF, заметки)
2. **Wiki** — переработанная база знаний (саммари, концепты, связи)
3. **Schema** — инструкции для агента (AGENTS.md / CLAUDE.md)

### Три операции

| Операция | Описание |
|----------|----------|
| **Ingest** | Агент читает новый источник и обновляет wiki |
| **Query** | Вопрос к скомпилированной карте знаний, не к сырым файлам |
| **Lint** | Проверка на битые ссылки, противоречия, устаревшие страницы |

---

## LLM-Wiki vs Классический RAG

| Параметр | RAG | LLM-Wiki |
|----------|-----|----------|
| **Когда собираются знания** | На каждый запрос | Заранее, при ingest |
| **Состояние** | Stateless | Stateful |
| **Хранилище** | Чанки + эмбеддинги | Markdown-страницы + wikilinks |
| **Поиск** | Топ-K по векторам | LLM-навигация по индексу |
| **Инфраструктура** | Векторная БД | Markdown-папка + агент |
| **Масштаб** | Тысячи-миллионы документов | ~100 источников, индекс в контексте |

### Ключевое отличие

> RAG = интерпретатор (каждый раз перечитывает исходники)  
> LLM-Wiki = компилятор (работа делается один раз, запросы к готовому артефакту)

## Архитектура Obsidian + LLM-Wiki

```
vault/
├── raw/          # Исходники (не изменяем)
├── wiki/         # Переработанные знания
├── index.md      # Карта знаний
├── log.md        # Журнал изменений
└── AGENTS.md     # Правила для LLM-агента
```

---

## Как агент ищет информацию

1. Открывает `index.md` (карта знаний)
2. Выбирает релевантные страницы
3. Переходит по `[[wikilinks]]`
4. Только если ответа нет — спускается в `raw/`

## Применение к ARGOS

ARGOS уже использует:
- ✅ Obsidian vault (`F:\debug\аргос`)
- ✅ Markdown-файлы
- ✅ `[[wikilinks]]` (ARGOS Memory Web)
- ✅ `AGENTS.md` / `CLAUDE.md`

### Что можно внедрить

1. **Raw sources:** `04 Project Mirror/` как источник истины
2. **Wiki:** `03 Memory/` как переработанные знания  
3. **Index:** `ARGOS Memory Web` как карта знаний
4. **Ingest pipeline:** Автоматическая обработка новых логов
5. **Lint:** Периодическая проверка связей в Obsidian
