# Fix: Зависание ARGOS при старте из-за прогрева AI

**Дата:** 2026-05-11

## Проблема

`main.py` блокируется при запуске, если локальные AI-модели (Ollama, GPU-серверы) медленно отвечают во время процедуры `WARMUP`. Это не даёт запуститься MCP и Telegram, создавая впечатление, что система "висит".

## План решения

1.  **Рефакторинг `main.py`**: Переместить логику "прогрева" (`_warmup_ollama`) в отдельный метод класса `ArgosOrchestrator` под названием `warmup_local_ai_in_background`.
2.  **Неблокирующий запуск**: Убрать вызов этой логики из конструктора `__init__`.
3.  **Фоновый режим**: Запускать новый метод `warmup_local_ai_in_background` в отдельном фоновом потоке *после* того, как `ArgosOrchestrator` будет полностью создан.

Это позволит ядру и MCP запуститься мгновенно, используя облачные провайдеры, пока локальные модели "прогреваются" в фоне.
