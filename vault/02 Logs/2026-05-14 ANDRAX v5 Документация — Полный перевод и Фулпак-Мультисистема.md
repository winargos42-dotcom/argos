## 1. Что такое ANDRAX?

ANDRAX — это платформа для пентеста и этичного хакинга, разработанная специально для Android-смартфонов и ARM-плат (Raspberry Pi и др.). ANDRAX работает нативно на Android и ведёт себя как полноценный Linux-дистрибутив, но при этом более мощный.

**Разработчик:** Weidsom Nascimento (The Cracker Technology — Advanced Pentest)  
**Начало разработки:** 08.09.2016 (Бразилия)  
**Международный релиз:** 05.10.2018  

### Почему Android + ARM?

- **Портативность** — у каждого есть смартфон и он всегда под рукой
- **Камуфляж** — легко раствориться в толпе, никто не подозревает, что в руках полноценный пентест-инструмент
- **Мощь ARM** — современная архитектура, превосходящая x86 в энергоэффективности и производительности на ватт
- **Сенсорный интерфейс** — запуск инструментов напрямую пальцем, без мыши
- **Вездеходность** — ваш смартфон проникает туда, куда ноутбук не пройдёт

## 2. Почему ANDRAX лучше других?

| Характеристика | Описание |
|----------------|----------|
| **Портативность** | Работает на Android 5+ и любой ARM-плате (включая Raspberry Pi) |
| **HardBased** | Продвинутая структура изоляции процессов; конфликтующие библиотеки и ресурсы сосуществуют в одной среде. Безопасное выполнение ненадёжного кода |
| **Современность** | Новые инструменты, отсутствующие в других системах. Никаких динозавров и устаревших утилит |
| **Стабильность** | Платформа тестируется бесконечно. Обновления только для критичных вещей. Не ломается |
| **Больше инструментов** | Больше инструментов и ресурсов, чем у конкурентов. Всё готово к работе «из коробки» |
| **Оптимизация** | Оптимизации включены по умолчанию. Работает на слабых устройствах с малым объёмом ОЗУ и низким энергопотреблением |
| **Легковесность** | Требует всего ~15 ГБ. Для сравнения: Kali Linux — ~40+ ГБ |
| **ИИ и ML** | Ресурсы для систем искусственного интеллекта, нацеленных на хакинг |

## 3. Сравнение: ANDRAX vs Termux vs NetHunter

| Параметр | ANDRAX | Termux | Kali NetHunter |
|----------|--------|--------|----------------|
| **Тип** | Полноценная пентест-платформа | Debian-эмулятор пакетов | Debian chroot |
| **Root** | Требуется для 100% возможностей | Не требуется (ограничивает) | Требуется |
| **Оптимизация** | Хардкодированная под пентест | Ручная настройка необходима | Средняя |
| **Среда** | Оптимизированная под тесты | Базовый Debian-окружение | Полный Linux |
| **Совместимость ARM** | Нативная | Нативная (но не все пакеты) | Требует chroot |
| **Размер** | ~15 ГБ | ~1-5 ГБ | ~20-40 ГБ |
| **Графический интерфейс** | DCO (динамические категории) | Нет | Полный KDE/Xfce |

**Тезис:** ANDRAX — это оружие, Termux — это мастерская. Termux позволяет установить много пакетов, но для пентеста нужна специально оптимизированная среда.

## 5. Архитектура ANDRAX (HardBased)

ANDRAX использует **HardBased** архитектуру — продвинутую структуру внутри Linux, изолирующую процессы и ресурсы. Это означает:

- Конфликтующие библиотеки (libs) могут сосуществовать
- Ненадёжный код выполняется в безопасной среде
- Возможны тесты, невозможные в обычном Linux (например, изолированное выполнение payload)
- Процессы работают в своих namespaces без влияния на основную систему

**Эквивалент в мире ARGOS:** использование `proot`, `chroot`, или Docker при наличии root.

## 11. Magisk ARGOS Module: подробное описание

```
/data/adb/modules/argos-system/
├── module.prop           # Название, версия, описание
├── post-fs-data.sh       # Настройка после монтирования ФС
│   └── Создание /dev/argos/
│   └── Установка прав 666 на USB/CAN/TTY
│   └── Патчинг SELinux (enforcing → permissive для ARGOS)
├── service.sh            # Автостарт сервисов
│   └── Запуск argos-bridge (UART ↔ TCP)
│   └── Запуск argos-can-up (если CAN-шилд обнаружен)
│   └── kolibri_daemon (если QEMU в фоне)
└── system/xbin/
    ├── argos-status       # Статус системы: USB, CAN, BLE, OBD, JTAG, CPU
    ├── argos-usb-setup    # Настройка USB-OTG + libusb
    ├── argos-can-up       # Подъём CAN-интерфейса через шлюз
    ├── argos-colibri      # ColibriAsmEngine: assemble/disassemble
    └── argos-bridge       # UART ↔ TCP прозрачный мост
```

**Permissions:** Все xbin исполняемы от любого UID (755). При запуске из Termux — проверка доступности `/data/argos/shared/`.

## 13. Порядок установки для новых устройств ARGOS + ANDRAX

### Шаг 1: Подготовка системы Android
```bash
# Enable Developer Options + USB Debugging
adb shell settings put global adb_enabled 1

# Root (Magisk)
# Русская локаль
adb shell settings put secure locale_preferences ru-RU,en-US

# ADB over WiFi
adb tcpip 5555
adb connect 192.168.1.149:5555
```

### Шаг 2: Magisk Module ARGOS
```bash
adb push argos-system-module/ /data/adb/modules/argos-system/
adb shell "su -c 'chmod -R 755 /data/adb/modules/argos-system/system/xbin/'"
```

### Шаг 3: Termux + Andrax
```bash
# Termux bootstrap
adb push termux-multitool-bootstrap.sh /sdcard/
# Запуск через Termux GUI (input text injection)
# Или через Termux:Widget shortcut
```

### Шаг 4: Установка ANDRAX v5
- Скачать APK с официального канала
- Установить через `adb install andraxv5.apk`
- Запустить, дать root-права, дождаться распаковки chroot (~15 ГБ)

### Шаг 5: Финальная калибровка
```bash
# В Termux
bash ~/argos-mobile/scripts/termux-multitool-bootstrap.sh
bash ~/argos-mobile/scripts/argos_final_termux.sh

andrax-install --update
```
