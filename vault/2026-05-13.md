### Использование (через ADB WiFi)
```bash
# Подключиться
adb connect 192.168.1.149:5555

# Root shell
adb shell "su -c 'id'"  # → uid=0(root)

# USB scan (после подключения OTG)
adb shell "su -c 'lsusb'"

# DD Backup partitions
adb shell "su -c 'dd if=/dev/block/bootdevice/by-name/boot of=/sdcard/boot_backup.img'"
adb shell "su -c 'dd if=/dev/block/bootdevice/by-name/modem of=/sdcard/modem_backup.img'"

# Frida/objection pentest
adb shell "su -c 'pm list packages'"  # все пакеты
adb shell "su -c 'cat /data/data/*/databases/*.db'"  # базы данных
```

### Для полного OTG-доступа
Требуется **USB-C OTG адаптер** + любое из устройств:
- CH340 USB-UART → `/dev/ttyUSB0`
- ELM327 OBD-II → OBD диагностика
- Scanmatik → через pyusb (needs root)
- CAN adapter → через `tsu` + `can-utils`
