Как установить yay в Arch Linux
Для установки yay вам потребуется сначала вручную собрать его из исходного кода, выполнив следующие шаги:
Установите необходимые инструменты сборки:
Для компиляции пакетов из AUR нужны git и группа пакетов base-devel.
sudo pacman -S --needed base-devel git 
Примечание: флаг --needed позволяет избежать повторной установки уже имеющихся пакетов.
Клонируйте репозиторий yay:
Перейдите в любую временную папку (например, в домашний каталог) и скачайте исходный код:
git clone https://aur.archlinux.org/yay.git 
Соберите и установите пакет:
Зайдите в созданную папку и запустите процесс сборки. Важно: команду makepkg нельзя запускать от имени root, используйте обычного пользователя.
cd yay makepkg -si 
Флаг -s автоматически установит недостающие зависимости, а -i установит сам yay после успешной сборки. [6, 7, 8, 9, 10] 
Основные советы
Не используйте sudo с yay: В отличие от pacman, помощник yay сам запросит пароль администратора только тогда, когда это потребуется (на этапе установки пакета).
Обновление системы: После установки вы сможете обновлять все пакеты (и из официальных репозиториев, и из AUR) одной командой yay.
Удаление папки сборки: После того как команда makepkg -si завершится, папку yay, созданную через git clone, можно удалить. [7, 9, 10, 11, 12, 13]
