# ARGOS-MUKHTAR ZeroGPU — Validation v2

**Статус:** код подготовлен и проверен локально. Новая версия ещё не загружена
в Hugging Face и не выполнялась на ZeroGPU. Не путайте с прежними двумя
реальными GPU-прогонами 50 + 50 шагов, где лучшая модель была на 50 шагах.

## Зачем

Предыдущий режим искал лучшую модель, наблюдая MAE на 128 X_test. Так
подбирать количество шагов нельзя, если мы хотим отдельно оценить обобщение.

Новый протокол использует 360 исходных train-примеров: разбивает на
**288 train / 72 val**, сохраняя доли четырёх сценариев, фиксирует индексы
SHA-256 и ни разу не использует 128 тестовых состояний при выборе модели.

На ZeroGPU выполняется **6 кандидатов** (seed 7/21/42, LR 0.0001/0.0003),
максимум 80 шагов на кандидата, каждые 10 шагов — проверка validation MAE,
ранняя остановка после 3 неулучшений; выбирается лучший snapshot среди
кандидатов и исходных весов. После завершения фиксированной сетки только один
раз оценивается ранее использовавшаяся выборка из 128 состояний. При выходе
за лимит времени поиск завершается ошибкой, а не выдаёт частичную таблицу
как полный результат.

**Методологическое ограничение:** исходная модель уже могла видеть все 360
teacher train states; прежние эксперименты уже смотрели на 128 holdout.
Поэтому это только корректный контроль **инкрементального дообучения**.
Новый действительно независимый benchmark потребует ранее неиспользовавшиеся
траектории/сценарии, лучше независимо собранные и с frozen protocol.

## Подключение без разрушения прежнего Space

1. В копию работающего Space (через новую ветку или PR) добавьте
   validation_search.py и validation_gradio_component.py рядом с app.py.
2. Внутри существующего блока with gr.Blocks(...) as demo: добавьте:

   from validation_gradio_component import mount_validation_panel
   mount_validation_panel()

3. Не удаляйте старый UI, не меняйте train_biolocator.py, исходную модель,
   датасет и требования. Убедитесь, что hardware остался **zero-a10g**,
   никакие paid Jobs не запускаются.
4. Прежде чем отправлять, проверьте python -m unittest discover -s tests -v
   и diff. HF публикацию выполняйте через **штатный авторизованный канал ARGOS**.
5. После публикации проверьте RUNNING, Gradio /config, а затем квоту до
   первого нажатия кнопки. Браузерный CPU preflight требует отдельного
   подтверждения, но не может доказать достаточность бесплатного остатка.

## Локальные тесты

    python -m unittest discover -s tests -v

11 тестов: воспроизводимость split, баланс сценариев, запрет утечек тестовой
выборки в критерий отбора, ограничение GPU-гридов, обработка невалидных
входов и честный отказ при отсутствии CUDA. Тесты используют искусственный
датасет для проверки алгоритма; **не являются результатом Мухтара на GPU**.
