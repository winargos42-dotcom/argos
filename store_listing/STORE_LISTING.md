## Short description (≤ 80 chars)
Self-hosted AI control panel. Connect to your own ARGOS server on your local network.

## Full description (≤ 4000 chars)

ARGOS turns your phone into a control panel for your own self-hosted AI ecosystem.

ARGOS is not a cloud service. There is no account to create, no subscription, and no data sent to the developer. You run the ARGOS server on hardware you already own (a home PC, a single-board computer like Orange Pi or Raspberry Pi, or a small server) and this app connects to it over your local network or VPN.

**What you get**

- Real-time status of every node in your ARGOS mesh — PC, Orange Pi, ESP32, phones, remote cloud relays
- Brain API heartbeat and node registry browser
- Local AI model runner (Ollama, llama.cpp) status with per-GPU load
- Home Assistant entity browser and basic controls
- MQTT topic inspector
- Self-heal notifications and Prometheus alerts feed
- Manual override of any automated action

**Why self-hosted**

Your data, your models, your network. ARGOS does not phone home, has no analytics, no ads, no third-party SDK. The only network connections are the ones you configure yourself to your own server.

**Who it is for**

Hobbyists and engineers running their own home AI stack. ARGOS assumes you know what a YAML file is, what an IP address is, and that you have already got the server side running. This is the mobile dashboard, not a tutorial.

**Open source**

The full system is available in the project repository. The mobile client is a thin companion; the heavy lifting happens on your server.
